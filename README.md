# 🔐 ESP32 Biometric Attendance System

A cloud-connected biometric attendance solution built around ESP32, fingerprint authentication, and real-time database integration.

This system enables fast and reliable attendance recording while providing centralized access to attendance records through a cloud backend.

---

## Overview

The project combines biometric authentication, wireless connectivity, and cloud-based data management into a compact embedded device suitable for educational institutions, offices, laboratories, and workforce management applications.

The device verifies user identity through fingerprint recognition and records attendance with accurate timestamps synchronized from network time servers.

---

## Key Features

* Fingerprint-based attendance authentication
* Real-time cloud synchronization
* Automatic timestamp generation
* Wi-Fi enabled operation
* OLED status display
* Duplicate attendance prevention
* Portable embedded design
* Battery monitoring support
* Automatic network reconnection

---

## Technology Stack
